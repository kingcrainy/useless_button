## The Useless Button 🎯

## Basic Details
**Sole Developer:** Mahendra Babu

**Project Description**
A beautifully over-engineered, CSS-animated button that does absolutely nothing except count your clicks and aggressively judge your life choices.

**The Problem (that doesn't exist)**
The internet simply doesn't have enough glowing interfaces that actively insult users in Malayalam for wasting their own time.

**The Solution (that nobody asked for)**
A sleek, interactive DOM-breaking experience that begs the user to reconsider their productivity while delivering high-tier passive aggression.

## Technical Details
**Technologies Used**
*   **HTML5 / CSS3:** Custom radial gradients, floating orb animations, and glassmorphism modals.
*   **Vanilla JavaScript:** Event listeners, randomized array outputs, and click milestone tracking.
*   **Embedded Audio:** Base64 WAV click sound.

**Installation & Run**
1. Download `useless-button(1).html`.
2. Double-click the file to open it in any browser.
3. Click the button. Realize it does nothing. Click it again anyway.

## Core Features & Mechanics
*   **Phantom Orbs:** Continuously floating background blobs designed to distract from the void.
*   **The 50-Click Milestone:** A modal popup that explicitly demands the user buy the creator a cigarette and a fruity drink as compensation for wasted time.
*   **Vibe-Coded Architecture:** Built entirely while listening to Hindi music in the background, opting for vibes over actual functionality.
